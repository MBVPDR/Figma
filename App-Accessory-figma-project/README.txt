پروژه طراحی اپلیکیشن فروش لوازم اکسسوری و گیفت

📱 معرفی پروژه
این پروژه شامل طراحی کامل UI/UX یک اپلیکیشن موبایل برای فروش لوازم اکسسوری، هدایا و محصولات گیفت می‌باشد. کاربران می‌توانند از طریق این اپلیکیشن:
محصولات مختلف را مشاهده و خریداری کنند
پرداخت درون‌برنامه‌ای انجام دهند
از محیطی جذاب و کاربرپسند استفاده کنند

🎨 محتویات پروژه
این ریپوزیتوری شامل:
تمام اسکرین‌های طراحی شده در Figma
کامپوننت‌های قابل استفاده مجدد
فایل‌های منابع (آیکون‌ها، تصاویر نمونه)
راهنمای استایل (رنگ‌ها، تایپوگرافی)

🛠 فناوری‌های پیشنهادی برای توسعه
markdown
- فرانت‌اند: React Native یا Flutter
- پرداخت: درگاه زرین‌پال یا idPay
- پایگاه داده: Firebase یا MongoDB

📂 ساختار فایل‌ها
/project-files
  /screens         # تمام اسکرین‌های طراحی شده
  /components      # کامپوننت‌های جداگانه
  /assets          # تصاویر و آیکون‌ها
  style-guide.md   # راهنمای استایل طراحی

🚀 نحوه استفاده از طراحی‌ها
فایل‌های Figma را می‌توانید در نرم‌افزار Figma باز کنید
برای خروجی کد از پلاگین Figma to Code استفاده نمایید
اندازه‌ها بر اساس استاندارد موبایل (360×640) طراحی شده‌اند
